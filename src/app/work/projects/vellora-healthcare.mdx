## Overview

**Vellora Healthcare** is an interactive frontend clinical care platform prototype designed to showcase modern digital healthcare booking for in-home medical visits. The client application demonstrates intuitive doctor discovery, appointment workflows, and patient management interfaces, with backend infrastructure currently under active development.

Created as a comprehensive healthcare UX and frontend engineering project, the platform models how patients can browse medical specialists, schedule home consultations, and manage digital health appointments through a fast, component-driven web experience.

## Key Features

- **Interactive Specialist Directory**: Client-side faceted filtering across medical specialists, clinical departments, and credentials.
- **Appointment Scheduling Flow**: Step-by-step interactive booking interface for selecting consultation times and entering patient visit details.
- **Patient & Clinician Portal Views**: Conceptual dashboard layouts illustrating patient appointment records and clinician schedule overviews.
- **Responsive Architecture**: Mobile-optimized layouts built with React 19, Next.js, and Tailwind CSS.
- **Backend In Progress**: Full-stack services (authentication, PostgreSQL database, and booking API) are actively under development.

## Technology Stack

- **Frontend**: React 19, Next.js, TypeScript, Tailwind CSS, Lucide React
- **Architecture**: Component-driven UI with responsive layout grids and optimized client state
- **Status**: Frontend live on Vercel; backend services in active development
