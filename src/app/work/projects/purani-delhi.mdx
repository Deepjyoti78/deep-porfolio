## Overview

**Purani Delhi** is an atmospheric, interactive web experience created as a visual and musical tribute to the heritage, sounds, and nostalgia of Old Delhi. 

Designed with warm sepia tones, vintage typography, and authentic visual treatments, it creates a cozy, reflective digital space where users can immerse themselves in curated acoustic and classic melodies while working, studying, or relaxing.

## Key Features

- **Embedded YouTube Audio Engine**: Custom headless player integration powered by the YouTube IFrame API, providing uninterrupted high-fidelity audio streams.
- **Rotating Vinyl Visualizer**: An analog vinyl record animation that dynamically spins during playback and smoothly halts on pause.
- **Procedural Film Grain**: Subtle SVG fractal noise overlay producing realistic vintage film grain and depth.
- **Vintage Transport Controls**: Custom track scrubbers, volume controls, play/pause toggles, and track metadata displays styled with antique brass and parchment hues.
- **Responsive Streetscape Artwork**: High-resolution atmospheric background artwork optimized for both desktop widescreen and mobile portrait viewports.
- **Live Local Time**: Elegant ambient clock displaying current time with a warm digital aesthetic.

## Technology Stack

- **Framework**: Next.js 16 (App Router)
- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, SVG noise filters, CSS animations
- **APIs**: YouTube IFrame API with custom React Context state management
