## Overview

**ScamAI** (ScamShield AI) is an end-to-end investigation platform engineered to detect, deconstruct, and explain employment scams before job seekers fall victim to fraudulent recruiters.

Rather than relying purely on opaque binary classifiers, ScamAI provides **explainable AI assessments** that clearly highlight red flags, evaluate corporate domain authenticity, extract suspicious URLs, and assess email reputation.

## Key Features

- **Automated Scam Detection**: Scans job descriptions, offer letters, and recruiter communication for deceptive language patterns, unrealistic compensation, and high-risk requests.
- **Trust Chain & Domain Verification**: Cross-references sender email domains with legitimate corporate registries, WHOIS records, and domain creation age to flag newly registered imposter domains.
- **Explainable Risk Scoring**: Generates human-readable breakdowns explaining exactly *why* a posting was flagged, empowering users with actionable safety guidance.
- **Automated Web Research**: Performs autonomous multi-source background lookups on companies to verify physical presence, Glassdoor/LinkedIn footprints, and active hiring campaigns.
- **Streamlined Investigation Flow**: Minimalist editorial frontend designed for swift multi-channel triage across desktop and mobile devices.

## Technology Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide React, Vite
- **Backend**: Python, FastAPI, Pydantic, Scikit-learn
- **Machine Learning**: Custom NLP preprocessing pipeline, feature extraction, and explainable inference
- **Deployment**: Vercel (Frontend), Cloud Backend
