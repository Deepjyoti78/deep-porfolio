## Overview

**The Library System** is a full-stack reservation and visitor management system designed around Japanese editorial design principles. Built to streamline reading room reservations, quiet study zone bookings, and physical check-ins, the platform delivers a quiet, distraction-free user experience paired with robust administrative controls.

## Key Features

- **4-Step Booking Wizard**: Intuitive visitor reservation flow supporting category selection, facility choice, calendar scheduling, and time slot reservations.
- **Reservation Retrieval & QR Passes (`/my-booking`)**: Visitors can retrieve their confirmed reservations at any time using their booking reference code or registered email, generating an interactive verified QR check-in pass.
- **Admin Dashboard & KPI Analytics**: Real-time management interface featuring active loan metrics, visitor volume counts, overdue trend graphs, and segmented status tabs.
- **Live Check-in Desk**: Quick check-in search scanner enabling desk staff to verify entry credentials, track seat occupancy, and manage walk-ins seamlessly.
- **Data Integrity & Automation**: Built-in SQLite database migration scripts, rate-limiting middleware, and transactional booking safeguards.

## Technology Stack

- **Frontend**: React, Vite, Tailwind CSS, Lucide React
- **Backend**: Node.js, Express.js REST API
- **Database**: SQLite with custom automated schema migrations and seed scripts
- **Security**: Rate limiting, token verification, and strict input validation
- **Styling**: Monochromatic Japanese editorial typography and clean layout architecture
