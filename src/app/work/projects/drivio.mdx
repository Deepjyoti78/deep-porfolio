## Overview

**DriveLoop** is a multi-vendor self-drive car rental platform built with a modular monolith architecture and a clean Scandinavian automotive visual identity. Uniting verified independent car rental companies with discerning travelers across major Indian metropolitan hubs (Delhi NCR, Gurgaon, Noida, Jaipur, and Chandigarh), DriveLoop delivers an end-to-end rental lifecycle: from faceted discovery and date filtering to multi-tenant fleet dispatch and administrative settlement.

Engineered with high transactional rigor, DriveLoop eliminates double-booking race conditions through PostgreSQL row-level locks, computes all financial ledgers in integer minor units (paise), and protects transactions with HMAC payment signatures.

## Concurrency-Safe Booking & Financial Precision

- **Concurrency-Safe Availability Engine**: Prevents double-booking race conditions during simultaneous reservations using PostgreSQL row-level locks (`SELECT ... FOR UPDATE`) within Prisma transactions. Resolves overlapping temporal intervals with exact boundary validation:
  $$\text{existingStart} < \text{requestedEnd} \quad\text{AND}\quad \text{existingEnd} > \text{requestedStart}$$
- **Zero-Floating-Point Integer Accounting**: All daily rental rates, 18% GST calculations, security deposits, vendor earnings, and refund estimates are computed strictly in integer paise (INR cents) to eliminate cumulative floating-point errors.
- **Cryptographic Payment Verification**: Seamless integration with Razorpay test mode utilizing HMAC-SHA256 signature verification for payment orders, authorizations, and webhook notifications.

## Key Features

- **Lakeside Cinematic Experience**: Distinctive full-bleed visual branding with frosted pill search capsule, dynamic instant booking indicators, and theme-adaptive warm ivory (`#F4EFEA`) and dark modes.
- **Interactive Fleet Explorer**: Faceted fleet search across Indian hubs with dynamic date/time interval filtering, transmission (Automatic/Manual), fuel type (Petrol/Diesel/EV), seating capacity, and real-time inspector drawer.
- **Transparent Escrow Checkout**: Itemized price breakdown (base fee, statutory GST, refundable deposit escrow, platform fee), primary driver license verification, and instant confirmation pass generation.
- **Multi-Tenant Vendor Portal**: Isolated host portal where fleet operators manage vehicle inventory, image galleries, maintenance blockout dates, dispatch handovers with odometer logging, and damage inspection reports upon return.
- **Host Earnings & Payout Ledger**: Automated 90% net host earnings calculation (10% platform commission), real-time available balance tracking, and bank payout requests.
- **Platform Administration Console**: Comprehensive executive dashboard with GMV telemetry, fleet utilization analytics, vendor KYC verification gates, dispute resolution, and vehicle moderation.
- **Customer Trip Management**: Lifecycle tracking (`CONFIRMED`, `ACTIVE`, `COMPLETED`, `CANCELLED`), tiered cancellation with automated refund estimation, downloadable printable tax invoices, and post-trip reviews.

## Technology Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, React Router v7, TanStack Query, Zustand, Lucide React
- **Backend**: Node.js, Express.js REST API, TypeScript, Prisma ORM
- **Database & Cache**: PostgreSQL 16, Redis 7
- **Security & Payments**: JWT with HTTP-only cookies, Helmet, Express-Rate-Limit, Razorpay SDK, HMAC-SHA256
- **Testing & DevOps**: Vitest, Docker & Docker Compose, Swagger/OpenAPI documentation
