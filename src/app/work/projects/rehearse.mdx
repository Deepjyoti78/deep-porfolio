## Overview

**Rehearse** is an end-to-end AI mock interview preparation platform engineered to bridge the gap between static question banks and authentic live interview performance. Inspired by mid-century modern editorial aesthetics, the platform places candidates across a virtual desk with calibrated AI hiring leads who listen, evaluate responses in real-time, ask unscripted pushback follow-ups, and generate actionable multi-criteria performance reports.

Unlike generic quiz tools, Rehearse simulates the full interview lifecycle—from role configuration and resume skill extraction to live webcam/microphone checks, speech recognition, and instant rubric-driven debriefs.

## Key Features

- **9-Stage End-to-End Interview Journey**: Complete structured preparation flow covering setup introduction, interview track selection, granular configuration, resume/JD personalization, AI persona selection, hardware diagnostics, the live virtual interview room, and comprehensive scorecards.
- **Multiple Calibrated Interview Tracks**: Deep question banks and tailored evaluation rubrics across Technical Architecture, Behavioral & Leadership (STAR), HR & Culture Fit, Coding & Algorithms, and Mixed Full-Loop rounds.
- **Adaptive AI Interviewer Personas**: Distinct AI interviewer personalities with calibrated speaking styles and pacing—from supportive principal mentors (Alex) to FAANG-style hiring bar-raisers (Morgan) and strict systems architects (Jordan).
- **Live Voice Speech-to-Text & Push-to-Talk**: Built-in Web Speech API integration transcribing candidate responses into text in real-time with continuous listening, dynamic waveform visualization, and audio volume meters.
- **Intelligent Semantic Evaluation Engine**: Dynamic multi-criteria scoring algorithm evaluating response length, technical concept coverage, trade-off analysis, and STAR structure, with accurate handling of unanswered questions.
- **Comprehensive AI Performance Report**: Instant post-interview debrief featuring overall percentile benchmark scores, competency breakdown progress bars, question-by-question model answers, and a prioritized learning roadmap.
- **Resume & Job Description Extraction**: Optional drag-and-drop resume upload and JD matcher to tailor questions specifically to candidate project experience.
- **Full Mobile Responsiveness**: Seamlessly responsive layout optimized for smartphones and desktops with warm editorial parchment styling.

## Technology Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide React, Canvas Confetti
- **Audio & Speech**: Web Speech API (`SpeechRecognition` & `SpeechSynthesis`), Web Audio API (`AudioContext`, `AnalyserNode`)
- **State & Architecture**: Context API, LocalStorage persistence, modular component design
- **Tooling & Build**: Vite, PostCSS, ESLint
