## Overview

**Pubali Health Care (MediHealth)** is an all-in-one digital healthcare platform engineered to make essential medical services accessible, fast, and transparent. The system bridges patients with verified pharmaceutical supplies, certified pathology lab testing, and certified doctor teleconsultations through a unified, high-performance web interface.

Built to address healthcare fragmentation, the platform delivers a streamlined patient experience—from dynamic symptom and prescription-based medicine search to automated doorstep delivery tracking, integrated diagnostic appointments, and secure checkout workflows.

## Key Features

- **Comprehensive Online Pharmacy**: High-speed catalog search for prescription and over-the-counter (OTC) medicines with categorized filters, dosage indicators, automated discount pricing tiers, and stock status indicators.
- **Diagnostic Lab Test Booking**: Interactive portal enabling patients to browse pathology packages, schedule sample pickups or walk-in lab tests, and receive digital diagnostic reports.
- **Doctor Consultation Scheduling**: Streamlined appointments wizard connecting patients to licensed medical professionals with time slot selection and consultation tier pricing.
- **Cart & Wishlist Engine**: Persistent multi-item cart management with dynamic price calculation, promotional coupon application, and instant checkout.
- **Integrated Payment Infrastructure**: Robust payment checkout integration supporting Cashfree SDK and Razorpay gateways for seamless UPI, cards, and net-banking transactions.
- **Order Tracking & Management**: Real-time order dispatch updates and status tracking from warehouse pharmacy fulfillment to doorstep delivery.
- **Direct Patient Support**: Built-in responsive communication channels and direct WhatsApp support integration for emergency inquiries and prescription assistance.

## Technology Stack

- **Frontend**: React 19, Vite, Tailwind CSS, Lucide React, React Router 7, Axios
- **Backend**: Django REST Framework, Python, Celery, Docker
- **Payments**: Cashfree SDK & Razorpay Integration
- **State & Data**: RESTful API architecture with real-time session caching and client-side persistence
- **Deployment**: Vercel (Frontend), Cloud Container Architecture
